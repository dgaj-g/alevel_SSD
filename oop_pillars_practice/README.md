# 2017 Past Paper Decoder — OOP Concepts

Interactive web activities for AS Software Systems Development (CCEA) covering the 2017 past paper Questions 5 & 6.

## Topics Covered
- Abstraction
- Encapsulation
- Inheritance
- Polymorphism

## Activities
1. **OOP Flashback** — Concept refresher with visual analogies and challenges (8–10 min)
2. **The Charity Scenario** — Deep-dive into the real-world scenario, Flag Day concept, and inheritance diagram (15–18 min)
3. **Code Builder** — Teach-then-build drag-and-drop for each exam question part (25–30 min)
4. **Exam Mode** — Fill-in-the-blanks under exam conditions with timer (10–12 min)

**Total: ~1 hour**

## Deployment (GitHub Pages)
1. Upload this folder as a subfolder to your GitHub repository
2. Go to **Settings > Pages**
3. Set source to **main** branch, root folder
4. Access via: `https://your-username.github.io/your-repo/as-ssd-2017-paper/`

## Technical Notes
- Pure vanilla HTML/CSS/JavaScript — no dependencies
- Each activity is a single self-contained HTML file
- Works offline — just open any HTML file in a browser
- Mobile responsive
