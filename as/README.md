# OLS AS SSD Platform

CCEA AS Software Systems Development: the coursework guide (build a game in Visual Studio 2019, chapter by chapter), on the same platform as A2 SSD with the AS colours (teal #0F5257, amber #F0A830).

## Links
- Landing page: https://dgaj-g.github.io/alevel_SSD/as/
- Pupils: https://script.google.com/a/macros/c2ken.net/s/AKfycbzoi3hgcvUb8-9lkX5wOby5isPFYl5AX867aVUxiHNhKFPVgsr3kLxhrA9NLRsqOaW_GA/exec?class=L6-26-27 (the 2026-27 L6 class; swap in any class made on the staff page). Add #cw to open the coursework guide.
- Staff: the same link without ?class= (Apps Script project "OLS AS SSD Platform").
- The staff passcode is a Script Property Damien sets himself. It is never in this repo.

## Folders
- src/: the AS changes only (colour tokens, strings, the guide renderer)
- tools/build-as.js: builds platform/ and server/Index.html from the A2 platform plus src/
- platform/: the built pupil and staff CSS
- server/Index.html: the built page Apps Script serves
- content/coursework/: the published chapters, pictures and the one pupil zip (pictures, sounds, data; no code)
- gates/: G9 colour tokens and contrast, G10 demo privacy, T1–T6 tick API

The Summit Ready demo solution is staff only and never enters this repo (G10 checks).
